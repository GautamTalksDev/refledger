# PRE-REGISTERED STOP CONDITION

This stop condition was written before any code was committed. Date: 2026-09-21.

## Condition

Within 90 days of the public site going live, at least ONE of the following must fire:

A. Fifty GitHub App installations on repositories not owned by me or by anyone I know personally.

B. Five thousand organic search sessions in a single calendar month across the public pages.

C. Three paying customers on any tier.

D. One external tool, publication or organisation citing the dataset or calling the public API in production.

If none fire: the numbers are published as they stand and the hosted service is shut down. The log, dataset and verifier remain published permanently.

## Weighting

Criterion D is the strongest signal and criterion C the weakest, because a funded incumbent (StepSecurity Artifact Monitor) already serves the enterprise alerting market and has since at least August 2025.

## Interim checkpoints

- first movement detected that I did not cause
- first high-severity batch correlation
- first stranger installs the App
- first external verification of the log
- first citation of the dataset
- first inbound from a maintainer

## Amendment policy

This file may be appended to but never edited. Any change is a new dated section stating what changed and why. Moving a threshold after seeing the numbers invalidates the test.
